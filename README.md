# NEON CLASH — 3v3 Arena Game

브라우저에서 바로 실행되는 오리지널 3대3 아레나 슈팅 게임입니다. 외부 라이브러리 없이 HTML, CSS, JavaScript만 사용합니다.

## 게임 규칙

- 파란 팀 3명과 빨간 팀 3명이 대결하며 먼저 10점을 얻는 팀이 승리합니다.
- 체력이 0이 된 캐릭터는 잠시 후 다시 시작합니다.
- 경기장 중앙의 초록색 회복 아이템은 체력 35를 회복합니다.
- 제한 시간이 끝나면 점수가 높은 팀이 승리합니다.
- 돌격형, 탱커형, 저격형 중 하나를 선택할 수 있습니다.
- 캐릭터마다 전투 방식과 필살기가 다릅니다.
- 경기가 끝나면 역할 선택 화면으로 돌아가 다른 캐릭터로 다시 시작할 수 있습니다.
- BLUE 팀의 최고 점수를 기기에 자동 저장하며, 앱을 다시 실행해도 기록이 유지됩니다.
- 휴대폰과 태블릿의 가로 화면에서도 역할 설명과 게임 시작 버튼이 모두 표시됩니다.
- 업데이트 시 최신 게임 파일을 먼저 불러와 이전 버전이 섞이는 문제를 방지합니다.

## 조작법

### PC

- 이동: `WASD` 또는 방향키
- 조준/공격: 마우스로 조준하고 왼쪽 버튼 또는 `Space`
- 일시정지: `P`

### 모바일

- 왼쪽 조이스틱: 이동
- 오른쪽 조이스틱: 조준 및 공격
- 오른쪽 위 버튼: 일시정지
- 오른쪽의 필살기 버튼: 캐릭터 고유 능력 사용

## 캐릭터

- **돌격형**: 빠른 이동과 연사. 필살기 사용 시 잠시 공격 속도가 크게 증가합니다.
- **탱커형**: 체력이 높고 받는 피해가 적습니다. 필살기 사용 시 보호막을 얻습니다.
- **저격형**: 이동과 연사는 느리지만 공격력이 높습니다. 필살기로 강력한 관통탄을 발사합니다.

## 실행 방법

`index.html`을 Chrome 같은 브라우저에서 열거나 저장소 폴더에서 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포

1. 저장소의 **Settings → Pages**로 이동합니다.
2. Source를 **Deploy from a branch**로 설정합니다.
3. Branch는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.
4. 배포가 끝나면 표시되는 주소에서 게임을 실행할 수 있습니다.

## 앱으로 설치

GitHub Pages 주소를 Android Chrome에서 연 뒤 메뉴의 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다. 설치 후에는 전체화면으로 실행되며, 한 번 불러온 게임은 오프라인에서도 실행할 수 있습니다.

Google Play 출시 준비 자료는 `play-store` 폴더에 있습니다. 현재는 PWA와 출시용 설정 초안까지 준비되어 있으며, 최종 AAB 빌드와 서명은 PC 및 만 18세 이상 소유자의 Play Console 계정이 필요합니다.

# NEON CLASH — 3v3 Arena Game

브라우저에서 바로 실행되는 오리지널 3대3 아레나 슈팅 게임입니다. 외부 라이브러리 없이 HTML, CSS, JavaScript만 사용합니다.

## 게임 규칙

- 파란 팀 3명과 빨간 팀 3명이 대결하며 먼저 10점을 얻는 팀이 승리합니다.
- 체력이 0이 된 캐릭터는 잠시 후 다시 시작합니다.
- 경기장 중앙의 초록색 회복 아이템은 체력 35를 회복합니다.
- 제한 시간이 끝나면 점수가 높은 팀이 승리합니다.

## 조작법

### PC

- 이동: `WASD` 또는 방향키
- 조준/공격: 마우스로 조준하고 왼쪽 버튼 또는 `Space`
- 일시정지: `P`

### 모바일

- 왼쪽 조이스틱: 이동
- 오른쪽 조이스틱: 조준 및 공격
- 오른쪽 위 버튼: 일시정지

## 실행 방법

`index.html`을 Chrome 같은 브라우저에서 열거나 저장소 폴더에서 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포

1. 저장소의 **Settings → Pages**로 이동합니다.
2. Source를 **Deploy from a branch**로 설정합니다.
3. Branch는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.
4. 배포가 끝나면 표시되는 주소에서 게임을 실행할 수 있습니다.

# NEON CLASH — 3v3 Arena Game

브라우저에서 바로 실행되는 오리지널 3대3 아레나 슈팅 게임입니다. 기본 게임은 HTML, CSS, JavaScript만 사용하며 온라인 시험판은 PeerJS를 사용합니다.

## 게임 규칙

- 파란 팀 3명과 빨간 팀 3명이 대결하며 먼저 10점을 얻는 팀이 승리합니다.
- 체력이 0이 된 캐릭터는 잠시 후 다시 시작합니다.
- 경기장 중앙의 초록색 회복 아이템은 체력 35를 회복합니다.
- 제한 시간이 끝나면 점수가 높은 팀이 승리합니다.
- 돌격형, 탱커형, 저격형 중 하나를 선택할 수 있습니다.
- 캐릭터마다 전투 방식과 필살기가 다릅니다.
- 경기가 끝나면 역할 선택 화면으로 돌아가 다른 캐릭터로 다시 시작할 수 있습니다.
- BLUE 팀이 승리할 때 걸린 최단 시간을 기기에 자동 저장하며, 앱을 다시 실행해도 기록이 유지됩니다.
- 휴대폰과 태블릿의 가로 화면에서도 역할 설명과 게임 시작 버튼이 모두 표시됩니다.
- 업데이트 시 최신 게임 파일을 먼저 불러와 이전 버전이 섞이는 문제를 방지합니다.
- 경기 종료 화면에서 경기 시간, 개인 처치·사망, 발사 수, 명중률, 가한 피해량을 확인할 수 있습니다.
- 개인 처치가 3킬과 6킬에 도달하면 선택한 역할의 필살기가 경기 중 자동으로 강화됩니다.
- 시작 화면과 일시정지 화면에서 난이도, 화면 흔들림, 진동을 설정할 수 있으며 선택값은 기기에 저장됩니다.
- 네온 공장, 크로스 광장, 트윈 통로 중 맵을 선택할 수 있으며 맵마다 장애물 배치와 분위기가 다릅니다.
- AI 캐릭터가 돌격형·탱커형·저격형 역할에 맞는 거리와 공격 속도로 전투합니다.
- AI는 장애물을 피해 이동하고, 체력이 낮으면 회복 아이템을 찾으며, 보이는 적에게만 공격합니다.
- 어려움 난이도에서는 이동 경로를 예측해 조준하고 팀원과 같은 목표를 집중 공격합니다.
- **웨이브 생존**에서는 총 5개의 공격을 버텨야 하며, 단계가 오를수록 적의 수와 체력·공격력이 증가합니다.
- **보스전**에서는 1,500 체력의 네온 가디언을 제한 시간 안에 격파해야 합니다.
- 네온 가디언은 체력에 따라 3개의 페이즈로 변하며 원형 탄막, 조준 공격, 돌진을 사용합니다.
- 강력한 패턴 전에는 경기장에 경고 범위가 표시되므로 보고 피할 수 있습니다.
- 2·3페이즈에서는 지원 로봇이 추가로 등장하고 공격 주기가 빨라집니다.
- 보스전 전용 체력바에서 남은 체력과 현재 페이즈를 확인할 수 있습니다.
- 공격, 명중, 처치, 필살기, 웨이브 시작과 보스 공격에 각각 다른 사운드 효과가 재생됩니다.
- 피격, 처치, 필살기, 웨이브 시작과 보스 공격은 상황에 맞는 진동 패턴을 사용합니다.
- 사운드와 진동은 설정에서 각각 끌 수 있으며 선택값이 기기에 저장됩니다.
- 경기가 끝나면 승패, 개인 처치 수와 선택한 모드에 따라 네온 코인을 획득합니다.
- 시작 화면의 강화소에서 역할별 체력, 공격력, 이동속도를 각각 최대 5단계까지 강화할 수 있습니다.
- 체력과 공격력은 단계마다 6%, 이동속도는 단계마다 3% 증가합니다.
- 보유 코인과 모든 강화 단계는 현재 기기에 자동으로 저장됩니다.
- 누적 처치, 경기 수, 승리, 웨이브 도달, 보스 피해 미션을 달성하면 네온 코인 보상을 받을 수 있습니다.
- 플레이 횟수·승리·누적 처치·보스 격파·최대 강화 기록에 따라 6개의 업적이 자동으로 해금됩니다.
- 미션 진행도, 보상 수령 여부와 업적 기록은 현재 기기에 자동으로 저장됩니다.
- 초보자 미션을 모두 완료하면 목록이 접히며, 원할 때 다시 펼쳐 확인할 수 있습니다.
- 일일 미션 3개는 매일, 주간 미션 3개는 매주 월요일에 새로운 진행도로 시작합니다.
- 누적 처치·승리·보스 격파 장기 미션은 한 단계를 완료하면 다음 목표와 더 큰 보상이 열립니다.

## 조작법

### PC

- 이동: `WASD` 또는 방향키
- 조준/공격: 마우스로 조준하고 왼쪽 버튼 또는 `Space`
- 일시정지: `P`

### 모바일

- 왼쪽 조이스틱: 이동
- 오른쪽 조이스틱: 조준 및 공격
- 오른쪽 위 버튼: 일시정지
- 오른쪽의 필살기 버튼: 캐릭터 고유 능력 사용

## 캐릭터

- **돌격형**: 빠른 이동과 연사. 필살기 사용 시 잠시 공격 속도가 크게 증가합니다.
- **탱커형**: 체력이 높고 받는 피해가 적습니다. 필살기 사용 시 보호막을 얻습니다.
- **저격형**: 이동과 연사는 느리지만 공격력이 높습니다. 필살기로 강력한 관통탄을 발사합니다.

### 스킬 강화

- **3킬 달성**: 스킬 LV.2가 되어 지속시간 또는 공격력이 증가합니다.
- **6킬 달성**: 스킬 LV.3이 되어 돌격형은 이동·연사 강화, 탱커형은 체력 회복, 저격형은 3발 관통탄을 얻습니다.
- 강화 단계는 해당 경기 동안 유지되며 새 경기를 시작하면 LV.1로 초기화됩니다.

## 실행 방법

`index.html`을 Chrome 같은 브라우저에서 열거나 저장소 폴더에서 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포

1. 저장소의 **Settings → Pages**로 이동합니다.
2. Source를 **Deploy from a branch**로 설정합니다.
3. Branch는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.
4. 배포가 끝나면 표시되는 주소에서 게임을 실행할 수 있습니다.

## 앱으로 설치

GitHub Pages 주소를 Android Chrome에서 연 뒤 메뉴의 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다. 설치 후에는 전체화면으로 실행되며, 한 번 불러온 게임은 오프라인에서도 실행할 수 있습니다.

Google Play 출시 준비 자료는 `play-store` 폴더에 있습니다. 현재는 PWA와 출시용 설정 초안까지 준비되어 있으며, 최종 AAB 빌드와 서명은 PC 및 만 18세 이상 소유자의 Play Console 계정이 필요합니다.

## 친구와 온라인 대전 (시험판)

1. 두 기기에서 같은 GitHub Pages 게임 주소를 엽니다.
2. 두 사람 모두 **친구와 온라인 대전**을 선택합니다.
3. 한 사람은 **방 만들기**를 누르고 표시된 6자리 코드를 친구에게 알려줍니다.
4. 친구는 코드를 입력해 참가하고, 방장이 **온라인 경기 시작**을 누릅니다.
5. 각 플레이어가 한 캐릭터를 조작하고 나머지 네 자리는 AI가 담당합니다.

- 별도 계정이나 채팅 없이 방 코드만 사용합니다. 코드는 아는 친구에게만 알려주세요.
- 온라인 대전은 인터넷 연결이 필요합니다. 학교·공공 Wi-Fi 등 일부 네트워크에서는 P2P 연결이 차단될 수 있습니다.
- 방장 기기가 경기를 계산하므로 방장이 페이지를 닫으면 경기가 종료됩니다.
- 온라인 시험판 기록은 싱글플레이 코인·미션·강화 기록에 영향을 주지 않습니다.
- 로비에서 두 플레이어의 역할과 준비 상태를 확인한 뒤 방장이 경기를 시작합니다.
- 경기 중 캐릭터 위의 **나**, **친구**, 역할별 **AI** 이름표로 조종 대상을 구분할 수 있습니다.
- 역할별 몸체 문양과 무기 모양이 다르며, 내 캐릭터는 흰색 테두리, 친구는 노란색 테두리로 표시됩니다.
- 경기 종료 후 연결을 끊지 않고 같은 방에서 바로 재대결할 수 있습니다.
- 방 코드 복사와 연결이 끊겼을 때 같은 코드로 다시 참가하는 기능을 지원합니다.
- 온라인 방장이 네온 공장·크로스 광장·트윈 통로 중 경기 맵을 선택할 수 있습니다.
- 온라인에서도 돌격형 오버드라이브, 탱커형 보호막, 저격형 관통탄을 사용할 수 있습니다.
- 개인 처치 3회와 6회에 역할 스킬이 LV.2와 LV.3으로 강화됩니다.
- 각 기기에 저장된 역할별 체력·공격력·이동속도 강화가 해당 플레이어에게 적용됩니다.
- 싱글플레이 설정에 저장된 사운드와 진동 효과가 온라인 경기에도 적용됩니다.
- 경기 종료 화면에서 개인 처치·사망·발사·명중률·피해량·스킬 단계를 확인할 수 있습니다.
